# Приёмочный прогон MVP (DND-082)

Шаблон для фиксации результатов реального прогона критериев `BR §7`
(`.claude/docs/REQUIREMENTS.md`). Это ручной acceptance-тест: пункты
отмечаются владельцем после того, как событие действительно произошло
на проде с живыми людьми, а не симулируется скриптом или API-вызовом.

Как использовать:
1. Проведите одну реальную кампанию D&D через продовую платформу.
2. По ходу кампании отмечайте пункты ниже (`[ ]` → `[x]`), вписывая дату
   и краткий факт (кто/что), а не пересказ сценария.
3. Когда все 6 пунктов отмечены — DND-082 закрывается мержем PR с этим
   файлом; отдельного кода эта задача не требует.
