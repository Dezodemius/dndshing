# DND-159 · Точный PDF по эталону Златобрада

## Контекст

В `develop` уже есть редактируемый четырёхстраничный лист и Playwright visual job, но текущая геометрия и тестовые PNG не соответствуют переданному владельцем PDF `Златобрад — LSS (1).pdf`. Новый эталон создан Headless Chrome 144, содержит четыре страницы A4 и должен быть воспроизведён на данных из `Златобрад — Long Story Short.json`.

## Требуемый результат

1. Нормализовать данные LSS в тестовую фикстуру контракта `CharacterSheet`. Не добавлять LSS-формат в production API.
2. Заменить печатную геометрию четырёх страниц на структуру нового эталона: все колонки, блоки, рамки, подписи, строки, значения, изображение и футеры.
3. Сохранить один DOM для экрана и печати, редактирование существующих полей и точный PATCH без потери `content`.
4. Зафиксировать шрифты и Chromium в тестовой среде.
5. Добавить обязательный visual gate с координатной системой 795 × 1123 px и максимальным геометрическим отклонением 3 px.
6. Сохранить проверки паритета значений, named layout, четырёх страниц A4, отсутствия AcroForm/JS и отсутствия видимых form controls в PDF.

## Ограничения

- Правила 5e берутся только из backend `computed`.
- Эталонные изображения неизменяемы и проверяются по SHA-256.
- Пиксельный допуск не может быть реализован одним процентом отличающихся пикселей: смещение целого блока на 4 px должно падать.
- Нельзя подменять результат готовым PDF или изображением страницы. Все значения должны формироваться из модели листа.
- Не менять внешний вид обычного интерактивного листа в этой задаче.
- Все пользовательские строки — через `ru.json`.

## Приёмка

- На фикстуре Златобрада получаются четыре A4-страницы.
- Размер каждой страницы после растеризации при 96 DPI — 795 × 1123 px.
- Все обязательные контуры и позиции отличаются от эталона не более чем на 3 px; пропущенный или лишний блок приводит к падению теста.
- Экранный и печатный DOM содержат одинаковые значения модели.
- Переполнение блокирует печать и называет проблемную секцию.
- `npm run build`, Vitest, Playwright E2E, visual gate и backend regression suite проходят.
- CRLF и исходные кодировки сохранены.
